📚 Mathematical Theory & Derivation

1. Amplitude Shift Keying (ASK / OOK)

In Binary ASK (specifically On-Off Keying or OOK), the transmitted waveform for bit \(b \in \{0, 1\}\) during symbol interval \(0 \le t \le T_b\) is:

\[ s(t) = \begin{cases} A \cos(2\pi f_c t + \phi_0), & \text{if } b = 1 \\ 0, & \text{if } b = 0 \end{cases} \]

Coherent Receiver (Correlator)

The received signal is multiplied by a locally generated, phase-synchronized reference carrier \(\cos(2\pi f_c t)\) and integrated over the symbol duration \(T_b\):

\[ y = \int_0^{T_b} r(t) \cos(2\pi f_c t) dt \]

When bit 1 is sent (assuming zero channel phase error), \(y = \int_0^{T_b} A \cos^2(2\pi f_c t) dt = A \frac{T_b}{2}\). When bit 0 is sent, \(y \approx 0\). The optimal decision threshold is \(\gamma = \frac{A T_b}{4}\).

Phase Error Sensitivity: If the channel introduces a carrier phase mismatch \(\theta\), the correlator output becomes \(y = A \frac{T_b}{2} \cos(\theta)\). If \(\theta = 90^\circ\), the output collapses to 0, causing massive bit errors!

Noncoherent Detector (Quadrature Envelope Detector)

When carrier phase \(\theta\) is unknown, a noncoherent receiver uses parallel In-phase (\(I\)) and Quadrature (\(Q\)) correlators:

\[ I = \int_0^{T_b} r(t) \cos(2\pi f_c t) dt, \quad Q = \int_0^{T_b} r(t) \sin(2\pi f_c t) dt \] \[ R = \sqrt{I^2 + Q^2} \]

Since \(I = A \frac{T_b}{2} \cos\theta\) and \(Q = -A \frac{T_b}{2} \sin\theta\), the envelope magnitude is \(R = A \frac{T_b}{2} \sqrt{\cos^2\theta + \sin^2\theta} = A \frac{T_b}{2}\), which is completely immune to phase error \(\theta\)!

2. Binary Frequency Shift Keying (BFSK)

In BFSK, bits 0 and 1 are mapped to distinct carrier frequencies \(f_0\) and \(f_1\):

\[ s_1(t) = A \cos(2\pi f_1 t + \phi_1), \quad s_0(t) = A \cos(2\pi f_0 t + \phi_0), \quad 0 \le t \le T_b \]

Coherent Dual Correlator Receiver

Two correlators match the two frequencies:

\[ y_0 = \int_0^{T_b} r(t) \cos(2\pi f_0 t) dt, \quad y_1 = \int_0^{T_b} r(t) \cos(2\pi f_1 t) dt \] \[ \text{Decision: Bit 1 if } y_1 > y_0, \text{ else Bit 0} \]

Noncoherent Dual Quadrature Detector

Computes envelope magnitudes for both tone branches:

\[ R_0 = \sqrt{I_0^2 + Q_0^2}, \quad R_1 = \sqrt{I_1^2 + Q_1^2} \] \[ \text{Decision: Bit 1 if } R_1 > R_0, \text{ else Bit 0} \]

3. FSK Tone-Spacing Orthogonality Derivation

The cross-correlation between two FSK tones spaced by \(\Delta f = |f_1 - f_0|\) with arbitrary phase difference \(\Delta \phi = \phi_1 - \phi_0\) over duration \(T_b\) is:

\[ \rho = \frac{1}{T_b} \int_0^{T_b} \cos(2\pi f_1 t + \phi_1) \cos(2\pi f_0 t + \phi_0) dt \]

Using trig identity \(\cos A \cos B = \frac{1}{2}[\cos(A-B) + \cos(A+B)]\) and ignoring high-frequency carrier terms (\(f_1 + f_0 \gg 1/T_b\)):

\[ \rho \approx \frac{1}{2 T_b} \int_0^{T_b} \cos(2\pi \Delta f t + \Delta \phi) dt \]

Condition A: Coherent Detection (\(\Delta \phi = 0\))

\[ \rho_{\text{coh}} = \frac{1}{2 T_b} \int_0^{T_b} \cos(2\pi \Delta f t) dt = \frac{\sin(2\pi \Delta f T_b)}{4\pi \Delta f T_b} = \frac{1}{2} \text{sinc}(2 \Delta f T_b) \]

For zero cross-correlation (\(\rho_{\text{coh}} = 0\)):

\[ \sin(2\pi \Delta f T_b) = 0 \implies 2\pi \Delta f T_b = k \pi \implies \Delta f = \frac{k}{2 T_b} = \frac{k R_b}{2} \quad (k = 1, 2, 3, \dots) \]

Minimum Coherent Tone Spacing: \(\Delta f_{\text{min, coh}} = \frac{1}{2 T_b} = \frac{R_b}{2} = 0.5 R_b\).

Condition B: Noncoherent Detection (Arbitrary Phase \(\Delta \phi\))

Expanding \(\cos(2\pi \Delta f t + \Delta \phi) = \cos(2\pi \Delta f t)\cos(\Delta \phi) - \sin(2\pi \Delta f t)\sin(\Delta \phi)\):

For orthogonality for all random phase angles \(\Delta \phi\), BOTH the in-phase integral and quadrature integral must equal zero simultaneously:

\[ \text{1. In-Phase Integral: } \int_0^{T_b} \cos(2\pi \Delta f t) dt = 0 \implies 2 \Delta f T_b = k \quad (k \in \mathbb{Z}^+) \] \[ \text{2. Quadrature Integral: } \int_0^{T_b} \sin(2\pi \Delta f t) dt = \frac{1 - \cos(2\pi \Delta f T_b)}{2\pi \Delta f} = 0 \implies 2\pi \Delta f T_b = 2 m \pi \implies \Delta f T_b = m \]

The joint condition requires \(\Delta f T_b = m \implies \Delta f = \frac{m}{T_b} = m R_b\) for integer \(m \ge 1\).

Minimum Noncoherent Tone Spacing: \(\Delta f_{\text{min, noncoh}} = \frac{1}{T_b} = R_b = 1.0 R_b\).

🔑 Key Takeaway: Noncoherent FSK requires double the frequency tone separation (\(1.0 R_b\)) compared to Coherent FSK (\(0.5 R_b\)) to guarantee zero cross-talk across arbitrary channel phase shifts!
